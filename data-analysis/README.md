# Year 7 Data Analysis booklet (Stage 4)

Lesson 10.01: Interpreting graphs (picture, column, sector and line graphs), based on the Exercise 10.01 questions in Test Yourself 10.
Artwork by Marni Tuala.

- `Year7-Interpreting-Graphs-10.01.pdf`: student booklet (A4, 4 pages). Print it double-sided so the exit ticket at the bottom of page 3 backs onto the blank bottom of page 4.
- `Year7-Interpreting-Graphs-10.01-Answers.pdf`: teacher answer key.
- To rebuild after editing questions or graph data in `build.js` or styles in `booklet.css`, run `node build.js` (needs Playwright installed globally).
