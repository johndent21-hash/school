# Year 7 Data Analysis booklet (Stage 4)

Lesson 1: Mean, median and mode. NSW Mathematics K–10 (2022), MA4-DAT-C-02.
Artwork by Marni Tuala.

- `Year7-Data-Analysis-Lesson1.pdf`: student booklet (A4, 22 pages). Print it double-sided so the exit ticket on page 21 backs onto the blank half of page 22.
- `Year7-Data-Analysis-Lesson1-Answers.pdf`: teacher answer key.
- To rebuild after editing questions in `build.js` or styles in `booklet.css`, run `node build.js` (needs Playwright installed globally).
