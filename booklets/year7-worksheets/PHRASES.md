# Worksheet phrases

Use these exact words on every worksheet, so students recognise each move from lesson to lesson.

The same phrases appear in four places: the HOW TO boxes, the speech bubbles, the working lines and the answer booklet.

## Speech bubbles: one plain instruction

| When the step asks students to… | Bubble |
|---|---|
| use a number line | Draw the jump. Write where you land. |
| use a number line for two moves | Add from left to right. Draw the jumps when there is a number line. |
| rewrite and work out | Rewrite + (−) as −. Then work it out. |
| cancel zero pairs | Take the difference. Which sign has more? |
| work on a story | Write a sum. Then answer the question. (Or "Write a number sentence…" for × and ÷.) |
| check someone's working | Is it right? Explain your answer. |
| find a missing number | Find the missing number. |

A bubble also says when the number lines stop: "The last one has no number line."

## Ideas and their working lines

| Idea | HOW TO wording | Working line |
|---|---|---|
| Adding a positive | Adding a positive number: move **right**. | `start at −3, move 5 right` / `= 2` |
| Adding a negative | Adding a negative number: move **left**. + (−4) means the same as − 4. | `= 3 − 5` / `= −2` |
| Zero pairs | A + and a − make a **zero pair**. They cancel out. So take the difference. The sign with more wins. | `9 − 4 = 5` / `− has more: −5` |
| Three or more numbers | Add from left to right, one jump at a time. | `= 5 + (−7)` / `= −2` |
| Subtracting a negative | Subtracting a negative: move **right**. − (−3) means the same as + 3. | `= 5 + 3` / `= 8` |
| Comparing | The number further **right** is larger. Colder means **lower**. | `−9 is left of −4` / `larger: −4` / `symbol: <` |
| Ordering | **Ascending**: smallest to largest. **Descending**: largest to smallest. | `smallest: −4` / `−4, −1, 0, 3` |
| Distance between | Count the steps. Across 0? Count to 0, then on from 0. | `3 to 0, 5 from 0` / `= 8` |
| Scales | The step is the difference between two labels ÷ the gaps between them. | `10 ÷ 5 = 2, step 2` / `? = 8` |
| Halfway | Find how far apart. Halve it. Move that far from the smaller one. | `10 apart, half is 5` / `−7 + 5 = −2` |
| Distance from zero | How many steps a number is from 0. Never negative. | `distances: 7 and 5` / `further: −7` |
| Opposites | The **opposite** is the same distance from 0, on the other side. | `opposite: 4`; for −(−n): `= opposite of −3` / `= 3` |
| Multiplying and dividing | **Same** signs: positive. **Different** signs: negative. | `different signs: −` or `same signs: +` / `= −12` |
| Equal groups | 3 × (−2) means 3 groups of −2. | `(−2) + (−2) + (−2)` / `= −6` |
| Three or more factors | Multiply two at a time, left to right. Even number of negatives: +. Odd: −. | `= −6 × 4` / `= −24` |
| Missing numbers (× and ÷) | Use the opposite operation. | `☐ = 5 × (−3)` / `☐ = −15` |
| Subtracting a positive | Subtracting a positive number: move **left**. | `move 3 left` / `= −5` |
| Change and difference | Change = new − old. Difference = higher − lower. | `5 − (−3)` / `= 5 + 3` / `= 8°C` |
| Averages | Average = total ÷ how many. | `total: −12` / `= −12 ÷ 4` / `= −3` |
| Order of operations | Brackets first. Then × and ÷, left to right. Then + and −, left to right. | one step a line, starting with `=` |
| Calculator keys | Use **(−)** for a negative number. Use **−** to subtract. Brackets around a negative after × or ÷. | `(−) 48 + 25 =` / `= −23` |
| Brackets on a calculator | Press ( and ) for brackets. | `bracket: −15` / `= −90` |
| Estimating | Round to the nearest 10, then check on the calculator. | `≈ −40 × 20 = −800` / `= −819` |
| Money | Money in is +. Money out is −. Below $0 means you owe money. | `30 − 45` / `= −$15` |
| Several steps | One number sentence a step. | `2 × 5 = 10` / `−6 + 10` / `= 4°C` |
| Stories | Up, rises and gains are **positive**. Down, falls and spending are **negative**. | `−4 + 9` / `= 5°C` |
| Missing numbers | How far is it from the first number to the answer, and which way? Right is +. Left is −. | `6 to the right` / `☐ = 6` |
| Is it right? | Work it out yourself first. Then compare. Say yes or no, and give the right answer. | working, then `No. The answer is −3.` or `Yes. Ben is right.` |

## Rules for writing

- Use a true minus sign (−), not a hyphen.
- Put brackets around a negative number that follows an operation: 3 + (−5), not 3 + −5.
- Each working line starts with `=` when it continues a calculation.
- Answers that are sentences start with Yes or No. The scaffold then reads "Yes / No. …".
- Units go on the answer line: `= 5°C`, `= −15 m`, `= −$25`, `= level 3`.
