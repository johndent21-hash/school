# Year 7 · Ch 11 · Complementary events worksheet

One double-sided A4 sheet (2 pages) for independent work. Outcome MA4-PRO-C-01.

- Mandelbrot theme (`feather` region), booklet blue `#3f63be`.
- Worked examples: pale grey, dashed border. Questions: pale blue.
- 4 worked examples, each labelled with the round it supports. 20 questions (Rounds 1–4 and 2 Challenge questions), scaffolding fades from fill-in-the-blank to blank.
- Answer key upside down at the bottom of page 2, plus a traffic-light self-check.

Build from the `booklets` folder:

```
node year7-single/ch11-complementary-events/build.js
```

The build checks every answer (stops if one is wrong), checks the layout and writes `Yr7_Ch11_Complementary_Events_Worksheet.pdf`.
