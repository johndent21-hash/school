# Year 7 · Ch 11 · Complementary events: extension worksheet

The extension partner to `../ch11-complementary-events`. Same layout, theme and stylesheet (read from that folder), one double-sided A4 sheet. Outcome MA4-PRO-C-01; all content stays within Stage 4.

- Round 1: complements with "more than", "at least", primes and multiples; are two events complementary?
- Round 2: P(not A) with fractions (simplest form), decimals and percentages.
- Round 3: three or more outcomes add to 1; spotting an impossible pair.
- Round 4: working backwards from P(not A) to a count.
- Challenge: two reasoning problems.

Build from the `booklets` folder: `node year7-single/ch11-complementary-events-extension/build.js`
