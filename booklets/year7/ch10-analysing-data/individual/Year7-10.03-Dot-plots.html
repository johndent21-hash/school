Worked example
Make up 8 values whose dot plot has a mode of 5, a cluster from 4 to 6, and an outlier at 12.
  1. Put the most dots at 5: 5, 5, 5
  2. Add values close by for the cluster: 4, 4, 6, 6
  3. Add one value far away for the outlier: 12

Lesson summaryMissed the lesson? Start here.
Drawing a dot plot
  1. Find the smallest and largest values.
  2. Draw a number line with an even scale.
  3. Put one dot per value above the line. Stack neatly.
  4. Add a title and label the axis.
Level 1
How many students have 2 siblings? What is the mode?
  1. Count the dots above 2: there are 4
  2. The tallest stack is above 1

Answer: 4 students; mode 1

Level 2
Draw a dot plot for: 3, 5, 4, 5, 6, 5, 4
  1. Smallest 3, largest 6: draw a line from 3 to 6
  2. Put one dot above the line for each value

Answer: the dot plot below (mode 5)

Level 3
What fraction of these 20 days were warmer than 25 °C?
  1. Count the dots above 26 and 27: 5 + 3 = 8
  2. Fraction = 8/20 = 2/5

Answer: 2/5 of the days (40%)

Extension
Describe the dot plot using a cluster and an outlier.
  1. Most values bunch together from 4 to 6
  2. 12 is far away from the rest

Answer: cluster from 4 to 6, outlier 12
