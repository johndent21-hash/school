Worked example
A shop’s sales doubled. On a poster, this year’s circle has twice the width and twice the height of last year’s. How many times bigger does it look?
  1. Width × 2 and height × 2
  2. The area (how big it looks) is 2 × 2 = 4 times as big
  3. Sales only doubled, so the picture exaggerates

Answer: it looks 4 times bigger

Lesson summaryMissed the lesson? Start here.
Is this graph fair?
  1. Does the vertical axis start at 0 (or show a break)?
  2. Is the scale even (equal gaps = equal amounts)?
  3. Are the title and axis labels there?
  4. Is all the data shown, with bars the same width?
Level 1
A column graph’s vertical axis starts at 90. What is the problem?
  1. Bar heights are measured from 90, not from 0
  2. So small differences look huge

Answer: it is misleading. Start the axis at 0.

Level 2
Scores of 60 and 64 on an axis starting at 58. How many times as tall does the 64 bar look? What is the real difference?
  1. Heights on the graph: 60 − 58 = 2 and 64 − 58 = 6
  2. 6 ÷ 2 = 3, so it looks 3 times as tall
  3. Real difference: 64 − 60 = 4

Answer: looks 3 times as tall; really only 4 more

Level 3
Redraw the Level 2 graph fairly.
  1. Start the vertical axis at 0 with an even scale
  2. Plot the same values: 60 and 64
  3. Add a title and label both axes

Answer: the bars now look almost the same, which is the truth

Extension
A picture is drawn twice as wide and twice as tall. How many times bigger does it look?
  1. Area grows by width × height
  2. 2 × 2 = 4

Answer: 4 times bigger, though the value only doubled
